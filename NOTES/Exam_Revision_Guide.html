AI & Computer Foundations

The building blocks: how computers work under the hood, and where AI fits in.

Generative AI & the AI/ML/DL Family

WHAT IS IT?

Gen AI creates new content (text, images, code) by learning patterns from huge datasets. AI is the broad goal of making machines act smart; ML is a subset that learns from data instead of fixed rules; DL is a subset of ML using multi-layer neural networks.

WHY USE IT?

Automates creative and analytical tasks, powers chatbots, recommendations, image generation and more.

TermScopeExample
AIBroadest field – any smart behaviourChess engine, Siri
MLLearns patterns from dataSpam filter, price prediction
DLML using deep neural networksFace recognition, ChatGPT
⚠️ EXAM TRAP
  • AI, ML and DL are not the same thing – DL ⊂ ML ⊂ AI (nested circles, not equal boxes).
  • 'Gen AI' specifically means content-generating AI, not all AI.
⚡DL is inside ML, ML is inside AI — think of nested circles, smallest to biggest.

Is AI Good or Bad?

Neither by itself — AI is a tool. Its impact depends on how it is designed, trained, and used.

WHAT IS IT?

A neutral technology that can help (medical diagnosis, accessibility) or harm (bias, misinformation, job displacement) depending on use.

WHY USE IT?

Understanding both sides helps you use AI responsibly.

KEY POINTS
  • Benefits: faster research, automation, accessibility tools, personalised learning.
  • Risks: bias in training data, misinformation, privacy loss, job displacement.
  • Responsible use = human oversight + ethical guidelines.

IDE, Terminal & File Types

WHAT IS IT?

IDE (Integrated Development Environment) is software to write, run and debug code (e.g. VS Code). Terminal is a text-based interface to give the computer direct commands.

WHY USE IT?

IDE speeds up coding with helpers (autocomplete, debugging); terminal gives precise control (installing packages, running scripts).

KEY POINTS
  • Common file types: .py Python script, .ipynb Jupyter notebook, .csv tabular data, .json structured data.
  • Code runs by: you write source code → interpreter/compiler translates it → CPU executes instructions → output is shown.
  • Python is interpreted — code runs line by line, no separate compile step needed.
⚡IDE = where you write code. Terminal = where you command the computer directly.

Conditions & Loops

How Python makes decisions and repeats actions — a favourite exam area.

if / elif / else & Indentation

marks = 72
if marks >= 90:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
else:
    print("Grade C")
OUTPUTGrade B
KEY POINTS
  • if checks a condition; elif checks another only if the previous ones were False; else runs when none matched.
  • Python uses indentation (spaces) instead of curly braces to define code blocks.
  • Only the first matching condition's block runs — the rest are skipped.
⚠️ EXAM TRAP
  • Inconsistent indentation causes an IndentationError — be consistent (4 spaces is standard).
  • Using if repeatedly instead of elif checks ALL conditions, which is slower and can run multiple blocks.
⚡if = first check, elif = else-if, else = default. Indentation is not optional in Python!

for loop vs while loop

LoopRuns when...Typical use
forIterating over a known sequence (list, range)Fixed number of steps
whileA condition stays TrueUnknown number of steps
for i in range(3):
    print(i)

n = 3
while n > 0:
    print(n)
    n -= 1
OUTPUT0 1 2
3 2 1
⚠️ EXAM TRAP
  • Forgetting to update the loop variable in a while loop causes an infinite loop.

break vs continue

KeywordEffect
breakStops the loop completely
continueSkips the rest of this iteration, loop continues
for i in range(5):
    if i == 3:
        break
    print(i)
OUTPUT0 1 2
⚡break = exit the loop now. continue = skip to the next round.

Defining Functions & return

def add(a, b):
    return a + b

result = add(4, 5)
print(result)
OUTPUT9
WHAT IS IT?

A function is a named, reusable block of code that performs a task, optionally taking inputs (parameters) and giving back an output.

WHY USE IT?

Avoids repeating code, makes programs organised and easier to test/debug.

print() vs return

print()return
PurposeDisplays value on screenSends value back to the caller
Usable later?No — output is gone after showingYes — can be stored in a variable
def show(x):
    print(x)
def give(x):
    return x

a = show(5)   # prints 5, a is None
b = give(5)   # nothing printed, b = 5
OUTPUT5
⚠️ EXAM TRAP
  • A function with only print() and no return gives back None if you try to store its result.

Local vs Global Variables

x = 10          # global
def show():
    x = 5       # local, separate variable
    print(x)
show()
print(x)
OUTPUT5 10
KEY POINTS
  • Local variables exist only inside the function where they're created.
  • Global variables exist outside functions and are visible everywhere (read access).
  • Use the global keyword to modify a global variable from inside a function.
⚡Local variables die when the function ends; global variables live for the whole program.

OUTPUT[2, 4, 6]
KEY POINTS
  • Lists can be passed into functions and returned from them just like any other value.

Python Data Structures

Four ways to store multiple values — knowing which to pick is a core exam skill.

Lists: append(), pop(), Sort & Reverse

nums = [3, 1, 4]
nums.append(9)      # add to end
nums.pop(0)          # remove index 0, returns it
nums.sort()           # ascending, in-place
nums.reverse()      # reverse order, in-place
print(nums)
OUTPUT[9, 4, 1]
KEY POINTS
  • append() adds one item to the end; pop(i) removes & returns the item at index i (default: last).
  • sort() changes the list itself; sorted(list) returns a new sorted list, original unchanged.
  • Looping: for item in list: or for i, item in enumerate(list): for index + value.
⚠️ EXAM TRAP
  • list.sort() returns None — don't do x = list.sort(), x will be None!

List vs Tuple vs Set vs Dictionary

FeatureListTupleSetDictionary
Syntax[1,2](1,2){1,2}{'a':1}
Mutable?YesNoYesYes
Ordered?YesYesNoInsertion order (3.7+)
Duplicates?AllowedAllowedNot allowedKeys unique, values can repeat
Access byIndexIndexNo indexingKey
⚠️ EXAM TRAP
  • Tuples are immutable — you cannot append/change items after creation.
  • Sets automatically drop duplicates and have no guaranteed order/index access.
  • Dictionary keys must be unique; adding the same key again overwrites the old value.
⚡List = changeable & ordered. Tuple = fixed & ordered. Set = unique & unordered. Dict = key→value pairs.

Dictionaries & Key-Value Pairs

student = {"name": "Divya", "age": 21}
print(student["name"])
student["age"] = 22          # update
student["city"] = "Hyderabad"  # add new key
print(student)
OUTPUTDivya {'name': 'Divya', 'age': 22, 'city': 'Hyderabad'}
KEY POINTS
  • Dictionaries store data as key: value pairs — access by key, not position.
  • dict.get('key') is safer than dict['key'] — avoids KeyError if key is missing.

Set Operations: Union, Subset, Superset

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # union
print(a & b)   # intersection
print({1,2}.issubset(a))     # subset check
OUTPUT{1, 2, 3, 4} {2, 3} True
KEY POINTS
  • Union (|) combines all unique elements from both sets.
  • Subset: every element of set A is in set B. Superset: B contains all of A's elements (reverse of subset).

Numerical Python

NumPy

Fast array maths — the foundation of data science computation.

NumPy Arrays vs Python Lists

WHAT IS IT?

NumPy provides the ndarray — a fast, fixed-type, multi-dimensional array object for numerical computing.

WHY USE IT?

Much faster than lists for maths (vectorised operations) and supports matrix/linear algebra operations lists can't do directly.

import numpy as np
a = np.array([1, 2, 3])
print(a * 2)              # element-wise, no loop needed
print([1,2,3] * 2)      # list: repeats the list!
OUTPUT[2 4 6] [1, 2, 3, 1, 2, 3]
⚠️ EXAM TRAP
  • Multiplying a Python list by 2 repeats it; multiplying a NumPy array by 2 multiplies each element.

Shape & reshape()

arr = np.array([1,2,3,4,5,6])
print(arr.shape)              # (6,)
b = arr.reshape(2, 3)
print(b)
print(b.shape)
OUTPUT(6,) [[1 2 3] [4 5 6]] (2, 3)
KEY POINTS
  • .shape tells you (rows, columns, ...) of an array.
  • reshape(r, c) changes the array's dimensions — total elements (r × c) must match the original count.
  • Use -1 in reshape to let NumPy auto-calculate that dimension, e.g. reshape(2,-1).
⚠️ EXAM TRAP
  • reshape() fails with a ValueError if r×c doesn't equal the original number of elements.

Element-wise Ops vs Matrix Multiplication vs dot()

OperationSymbolWhat it does
Element-wise*Multiplies matching positions, same shape needed
Matrix multiply@ or np.matmulRows × Columns (linear algebra rule)
dot productnp.dot(a,b)Sum of element-wise products (vectors) or matrix multiply (2D)
a = np.array([[1,2],[3,4]])
b = np.array([[5,6],[7,8]])
print(a * b)      # element-wise
print(a @ b)      # matrix multiplication
OUTPUT[[ 5 12] [21 32]] [[19 22] [43 50]]
⚠️ EXAM TRAP
  • * is NEVER true matrix multiplication in NumPy for 2D arrays — use @, np.matmul() or np.dot().

hstack(), vstack() & Broadcasting

a = np.array([1,2]); b = np.array([3,4])
print(np.hstack((a,b)))   # side by side
print(np.vstack((a,b)))   # stacked as rows

m = np.array([[1,2,3],[4,5,6]])
print(m + np.array([10,20,30]))  # broadcasting
OUTPUT[1 2 3 4] [[1 2] [3 4]] [[11 22 33] [14 25 36]]
KEY POINTS
  • hstack joins arrays horizontally (columns), vstack joins vertically (rows).
  • Broadcasting lets NumPy apply an operation between arrays of different but compatible shapes without manual loops.
⚡Broadcasting 'stretches' the smaller array to match the bigger one's shape — no copying happens in memory.

Random Numbers: randn() vs randint()

FunctionDistributionExample
np.random.randn(n)Standard Normal (mean 0, std 1), can be negative-0.42, 1.13, ...
np.random.randint(lo,hi,n)Uniform whole numbers in a range3, 7, 1, 9, ...
⚠️ EXAM TRAP
  • randn() gives continuous decimal values around 0; randint() gives whole numbers in a fixed range — don't mix them up.

Standardization vs Min-Max Scaling

StandardizationMin-Max Scaling
Formula(x - mean) / std(x - min) / (max - min)
Output rangeNo fixed range, centered at 00 to 1
Use whenData may have outliers, normal-ish distributionYou need a bounded range
⚡Standardization centers data around 0; Min-Max squashes data into [0,1].
TOPIC CHECK
Which scaling method centers data with mean 0 and standard deviation 1?
  1. Min-Max Scaling
  2. Standardization
  3. Broadcasting
  4. Normalization by sum
Show Answer
Answer: B. Standardization (Z-score scaling) transforms data to have mean 0 and standard deviation 1.

Pandas

The go-to library for tabular (spreadsheet-like) data in Python.

Why Pandas? (Problems with NumPy)

WHAT IS IT?

Pandas builds on NumPy to give labelled, table-like data structures: Series (1D) and DataFrame (2D).

WHY USE IT?

NumPy arrays hold only one data type and have no column names — hard to work with real-world mixed data (names, dates, numbers).

SeriesDataFrame
Dimensions1D (like a single column)2D (rows & columns, like a spreadsheet)
Examplepd.Series([1,2,3])pd.DataFrame({'a':[1,2]})

Reading Data & Exploring: info(), describe()

import pandas as pd
df = pd.read_csv("data.csv")
df.info()          # column types, non-null counts
df.describe()     # mean, std, min, max, quartiles
KEY POINTS
  • info() → structure: column names, dtypes, missing value counts.
  • describe() → statistics: count, mean, std, min, 25%/50%/75%, max (numeric columns only, by default).

loc vs iloc

lociloc
Selects byLabel / column nameInteger position (index number)
Exampledf.loc[0, 'name']df.iloc[0, 1]
End of rangeInclusiveExclusive (like normal Python slicing)
⚠️ EXAM TRAP
  • df.loc[0:2] includes row label 2; df.iloc[0:2] stops before position 2 — classic exam trick.

Renaming Columns & inplace

df.rename(columns={"old":"new"}, inplace=True)
# same as: df = df.rename(columns={"old":"new"})
⚠️ EXAM TRAP
  • inplace=True modifies the DataFrame directly and returns None — don't assign it back: df = df.rename(..., inplace=True) makes df become None!

Filtering Data

adults = df[df["age"] >= 18]
seniors = df[(df["age"] > 60) & (df["city"] == "Pune")]
KEY POINTS
  • Filtering uses a Boolean condition inside df[ ] — rows where condition is True are kept.
  • Combine conditions with & (and), | (or) — each condition needs its own parentheses.
⚠️ EXAM TRAP
  • Using Python's and/or instead of &/| on Pandas conditions raises an error.

Missing Values: Forward Fill vs Backward Fill

MethodFills a gap with...
df.fillna(value)A fixed value you choose
ffill() (forward fill)The previous valid value above it
bfill() (backward fill)The next valid value below it
df["marks"].fillna(df["marks"].mean(), inplace=True)
df["temp"].ffill(inplace=True)
⚠️ EXAM TRAP
  • Always check df.isnull().sum() before deciding to drop or fill — dropping too many rows loses data.

groupby & Aggregate Functions

df.groupby("department")["salary"].mean()
df.groupby("department").agg({"salary":"mean","age":"max"})
OUTPUTdepartment HR 45000.0 IT 62000.0 Name: salary, dtype: float64
KEY POINTS
  • groupby() splits data into groups by a column, then applies an aggregate function (mean, sum, count, max...) to each group.
  • Think: Split → Apply → Combine.
⚡loc = label-based, iloc = position-based. groupby = split-apply-combine.
TOPIC CHECK
df.loc[0:2] on a default-indexed DataFrame returns how many rows?
  1. 2 rows
  2. 3 rows
  3. 1 row
  4. Depends on iloc
Show Answer
Answer: B. loc's range is label-inclusive, so index 0,1,2 — that's 3 rows (unlike iloc which would exclude 2).

JSON & API Data

The universal language APIs use to send data.

Why JSON Matters & Its Structure

WHAT IS IT?

JSON (JavaScript Object Notation) is a lightweight text format for storing and exchanging structured data using key-value pairs.

WHY USE IT?

It's the standard format APIs use to send/receive data — human-readable and easy for programs to parse.

{
  "name": "Inception",
  "year": 2010,
  "genres": ["Sci-Fi", "Thriller"]
}
KEY POINTS
  • JSON objects use { } with "key": value pairs; arrays use [ ].
  • Values can be strings, numbers, booleans, null, objects, or arrays (nested).

Python Dictionaries & JSON Conversion

import json
data = {"name": "Divya", "age": 21}
text = json.dumps(data)     # dict -> JSON string
back = json.loads(text)     # JSON string -> dict
print(type(text), type(back))
OUTPUT<class 'str'> <class 'dict'>
KEY POINTS
  • json.dumps(): Python object → JSON string. json.loads(): JSON string → Python object.
  • A JSON object maps almost 1-to-1 onto a Python dictionary.
⚠️ EXAM TRAP
  • dumps (with an 's') = dump to STRING; load/loads reversed — students often mix these up.

Parsing API Responses & Nested JSON

response = {
  "results": [
    {"title": "Movie A", "rating": 8.1},
    {"title": "Movie B", "rating": 7.4}
  ]
}
for movie in response["results"]:
    print(movie["title"], movie["rating"])
OUTPUTMovie A 8.1 Movie B 7.4
KEY POINTS
  • API responses are usually nested JSON: objects inside arrays inside objects — access step by step using keys/indices.
  • Always check the structure (print it or check docs) before writing extraction code.
⚡dumps() = dict→string, loads() = string→dict. Nested JSON = drill down key by key.

sqlite3 & PRAGMA

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()
cur.execute("PRAGMA table_info(students)")
print(cur.fetchall())
KEY POINTS
  • sqlite3 is Python's built-in module to connect to and query SQLite database files.
  • PRAGMA commands inspect or configure the database itself (e.g. table_info lists a table's columns).
⚠️ EXAM TRAP
  • PRAGMA is SQLite-specific syntax for metadata/settings — it is not a normal data query.

SELECT, WHERE, DISTINCT & ORDER BY

SELECT DISTINCT city FROM students
WHERE age > 18
ORDER BY city ASC;
KEY POINTS
  • SELECT picks columns; WHERE filters rows before grouping; DISTINCT removes duplicate rows/values.
  • ORDER BY col ASC/DESC sorts the final result (default is ascending).

WHERE vs HAVING

WHEREHAVING
FiltersIndividual rowsGroups (after GROUP BY)

HAVING COUNT(*) > 5;
⚠️ EXAM TRAP
  • You cannot use aggregate functions like COUNT() inside WHERE — that's exactly what HAVING is for.
⚡WHERE filters rows first; HAVING filters groups after GROUP BY.

Combining Tables

SQL Joins & Normalization

Merging data across tables — a guaranteed exam topic.

Normalization (Quick Idea)

WHAT IS IT?

Organising a database to reduce data duplication and keep relationships clean by splitting data into related tables.

WHY USE IT?

Prevents inconsistent/duplicate data and saves storage — e.g. storing a customer once, referenced by ID in many orders.

INNER JOIN vs LEFT JOIN vs RIGHT JOIN vs OUTER JOIN

Join TypeReturns
INNER JOINOnly rows that match in BOTH tables
LEFT JOINAll rows from left table + matches from right (unmatched = NULL)
RIGHT JOINAll rows from right table + matches from left (unmatched = NULL)
FULL OUTER JOINAll rows from both tables; unmatched sides filled with NULL
-- Students table: id, name
-- Marks table: student_id, score
-- A student with no marks row:
SELECT s.name, m.score
FROM students s
LEFT JOIN marks m ON s.id = m.student_id;
-- That student still appears, score = NULL
⚠️ EXAM TRAP
  • INNER JOIN drops unmatched rows from both sides — easy to accidentally lose data.
  • SQLite does not support RIGHT JOIN/FULL OUTER JOIN directly (can simulate with LEFT JOIN + UNION).
⚡INNER = only matches. LEFT = everything on the left, matched or not. RIGHT = mirror of LEFT.
TOPIC CHECK
Table A has 5 rows, Table B has 3 matching + 2 non-matching rows relative to A. How many rows does INNER JOIN return (assuming 1-to-1 matches)?
  1. 5
  2. 8
  3. 3
  4. 2
Show Answer
Answer: C. INNER JOIN only returns rows where a match exists in both tables — here that's 3.

Machine Learning & EDA

Before building any model, you must understand your data — that's EDA.

Intro to ML & Dependent vs Independent Features

WHAT IS IT?

Machine Learning lets computers learn patterns from data to make predictions, without being explicitly programmed with rules.

WHY USE IT?

EDA (Exploratory Data Analysis) is the process of visually/statistically summarising data to find patterns, trends and issues before modelling.

Independent Feature (X)Dependent Feature (y)
RoleInput(s) used to predictOutput we want to predict
Example (Iris)Petal length, sepal widthSpecies (the target)
⚠️ EXAM TRAP
  • The dependent feature is also called the 'target' or 'label' — it depends ON the independent features, not the other way around.

Quartiles, IQR & Outliers

Q1 = df["marks"].quantile(0.25)
Q3 = df["marks"].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
KEY POINTS
  • Quartiles split sorted data into 4 equal parts: Q1 (25%), Q2/median (50%), Q3 (75%).
  • IQR = Q3 − Q1 measures the spread of the middle 50% of data.
  • Outliers: values below Q1 − 1.5×IQR or above Q3 + 1.5×IQR (common rule used by box plots).
⚡IQR = Q3 − Q1. Anything beyond 1.5×IQR past Q1/Q3 is a likely outlier.

⚠️ EXAM TRAP
  • Correlation only measures linear relationships — two variables can have a strong pattern that correlation completely misses (e.g. a U-shape).

Heatmap Interpretation

WHAT IS IT?

A heatmap colours a correlation matrix so patterns are visible at a glance — typically dark/warm colours for strong positive, cool colours for strong negative.

WHY USE IT?

Lets you scan relationships between many variables at once instead of reading numbers one by one.

import seaborn as sns
sns.heatmap(df.corr(), annot=True, cmap="coolwarm")

Correlation vs Causation

WHAT IS IT?

Correlation means two variables move together statistically. Causation means one variable directly causes the change in another.

WHY USE IT?

Confusing the two leads to wrong conclusions — a classic example: ice-cream sales and drowning both rise in summer (correlated), but ice cream doesn't cause drowning (a third factor, heat, causes both).

⚠️ EXAM TRAP
  • 'X and Y are correlated' never proves 'X causes Y' — there could be a hidden third variable, or the relationship could be reversed.
⚡Correlation is a clue, not proof. Causation needs controlled experiments, not just a heatmap.

Responsible Coding

Ethics, Security & Git

Protecting secrets and using technology responsibly.

Technology Ethics

WHAT IS IT?

Applying moral principles — fairness, honesty, privacy, responsibility — to how technology is built and used.

WHY USE IT?

Prevents harm: biased algorithms, privacy violations, and misuse of personal or sensitive data.

Why API Keys Are Sensitive & Environment Variables

# BAD: hardcoded key visible to anyone with the code
api_key = "sk-12345abc..."

# GOOD: stored in a .env file, loaded at runtime
import os
from dotenv import load_dotenv
load_dotenv()
api_key = os.getenv("API_KEY")
KEY POINTS
  • An exposed API key can be used by anyone — leading to stolen data, unexpected bills, or service abuse in your name.
  • Environment variables keep secrets outside your source code, so they aren't visible in the file itself.
  • A .env file stores these secrets locally and should never be committed to Git.
⚠️ EXAM TRAP
  • Hardcoding a key directly in a .py file that gets pushed to GitHub is one of the most common real-world security mistakes.

Git Key Security

KEY POINTS
  • Add .env and any secret files to .gitignore so Git never tracks/uploads them.
  • If a key is accidentally pushed to a public repo, it must be treated as compromised — revoke/regenerate it immediately.
  • Never share API keys in screenshots, chat messages, or public forums.
⚡Keys go in environment variables, never in code. .gitignore keeps secrets out of version control.
TOPIC CHECK
You accidentally pushed your API key to a public GitHub repo. What's the correct FIRST step?
  1. Delete the repo and hope no one saw it
  2. Immediately revoke/regenerate the key
  3. Change the key's variable name
  4. Make the repo private only
Show Answer
Answer: B. Once exposed publicly, a key must be treated as compromised — revoking/regenerating it is the only safe fix; deleting history doesn't undo exposure.

Hands-on Case Study

TMDB API

A real end-to-end walkthrough tying APIs, JSON and security together.

The TMDB Workflow

🎬API Key → Secure Storage → API Request → Response → JSON → Required Data
KEY POINTS
  • 1. Create an API Key on the TMDB website (account → API settings).
  • 2. Store it securely in an environment variable / .env file, never hardcoded.
  • 3. Send a request with requests.get(), passing the key as a parameter.
  • 4. Get the response and check the status code (200 = success).
  • 5. Parse the JSON response into a Python dictionary.
  • 6. Extract only the fields you actually need (title, rating, poster, etc.).

TMDB Hands-on Example

import os, requests
API_KEY = os.getenv("TMDB_API_KEY")
url = "https://api.themoviedb.org/3/movie/popular"
r = requests.get(url, params={"api_key": API_KEY})

if r.status_code == 200:
    data = r.json()
    for movie in data["results"][:3]:
        print(movie["title"], "-", movie["vote_average"])
else:
    print("Error:", r.status_code)
OUTPUTMovie A - 8.1 Movie B - 7.6 Movie C - 7.4
⚠️ EXAM TRAP
  • Always check status_code before trying to parse JSON — an error response may not contain the fields you expect.
⚡Every real API project follows the same shape: get key → secure it → request → parse JSON → use the data.

Quick Reference

⚡ Last-Minute Exam Traps

= vs ==

= assigns a value; == compares two values for equality.

if / elif / else

Only ONE block runs — the first True condition wins.

Indentation

Python uses spaces, not braces, to define blocks. Be consistent!

break vs continue

break exits the loop; continue skips to the next round.

print vs return

print() only displays; return sends a usable value back.

Local vs Global

Local variables die when the function ends.

append vs pop

append() adds to the end; pop() removes & returns an item.

List vs Tuple vs Set vs Dict

Ordered+mutable / ordered+fixed / unique+unordered / key-value.

Mutable vs Immutable

Lists, dicts, sets change in place. Tuples & strings don't.

Sorting vs Reversing

sort() orders values; reverse() just flips current order.

NumPy array vs Python list

Arrays: fixed type, fast maths, element-wise ops. Lists: mixed types, repeat with *.

reshape()

New shape's total elements must match the original count.

Element-wise vs Matrix Mult.

* multiplies positions; @ / matmul does true matrix multiplication.

dot()

Sum of element-wise products (vectors) or matrix multiply (2D).

Broadcasting

NumPy auto-expands smaller arrays to match shapes — no manual loop needed.

randn vs randint

randn(): normal decimals around 0. randint(): whole numbers in a range.

Standardization vs Min-Max

Standardize → mean 0/std 1. Min-Max → squashes into [0,1].

Series vs DataFrame

Series = 1 column. DataFrame = full table (rows & columns).

loc vs iloc

loc = label-based (end inclusive). iloc = position-based (end exclusive).

Forward vs Backward Fill

ffill uses the value above; bfill uses the value below.

WHERE vs HAVING

WHERE filters rows before grouping; HAVING filters groups after.

Primary vs Foreign Key

Primary = unique ID for its own table. Foreign = link to another table's key.

INNER vs LEFT JOIN

INNER = only matches. LEFT = all of left table + matches.

Histogram vs Bar Chart

Histogram = continuous numeric distribution. Bar = discrete categories.

Correlation vs Causation

Moving together ≠ one causing the other.

GET vs POST

GET retrieves data via the URL. POST sends data in the request body.

API Key vs Env Variable

The key is the secret; the env variable is where you safely store it.

JSON vs Python Dict

JSON is a text format; a dict is the in-memory Python object it maps to.
