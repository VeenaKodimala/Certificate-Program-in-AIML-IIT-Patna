📋 List

[ ]
✓ Ordered ✓ Mutable ✓ Allows Duplicates ✓ Indexed
Create fruits = ["apple", "banana", "cherry"]
Add
fruits.append("mango") Adds "mango" to the end
fruits.insert(1, "grape") Inserts "grape" at index 1
fruits.extend(["kiwi", "lime"]) Adds multiple items to the end
Remove
fruits.remove("banana") Removes first occurrence of "banana"
fruits.pop() Removes & returns the last item
fruits.pop(0) Removes & returns item at index 0
del fruits[2] Deletes item at index 2
fruits.clear() Removes all items (empty list remains)
Access
fruits[0] First item → "apple"
fruits[-1] Last item → "cherry"
fruits[1:3] Slice — items from index 1 to 2
Check / Info
"apple" in fruits Returns True if "apple" is in list
fruits.index("banana") Returns the index of "banana"
fruits.count("apple") How many times "apple" appears
Modify
fruits[0] = "orange" Replace item at index 0 with "orange"
fruits.reverse() Reverses the list in-place
💡 Use append to add one item, extend to add many, insert when position matters.

📦 Tuple

( )
✓ Ordered ✗ Immutable ✓ Allows Duplicates ✓ Indexed
Create coords = (10, 20, 30)
Add
coords + (40,) Creates a new tuple — original unchanged
coords = coords + (40,) Reassign to include new value
Remove
— (not possible directly) Tuples cannot be changed after creation
coords = list(coords) Convert to list → edit → convert back
del coords Deletes the entire tuple variable
Access
coords[0] First element → 10
coords[-1] Last element → 30
coords[0:2] Slice → (10, 20)
x, y, z = coords Unpack — x=10, y=20, z=30
Check / Info
20 in coords Returns True if 20 is in tuple
coords.index(20) Returns index of value 20
coords.count(10) How many times 10 appears
💡 Tuples are frozen lists — use them when data should NOT change (e.g., coordinates, RGB values, database records).

🔵 Set

{ }
✗ Unordered ✓ Mutable ✗ No Duplicates ✗ Not Indexed
Create colors = {"red", "green", "blue"}
Add
colors.add("yellow") Adds one item (ignored if already exists)
colors.update(["pink","white"]) Adds multiple items at once
Remove
colors.remove("red") Removes "red" — error if not found
colors.discard("red") Removes "red" — no error if not found
colors.pop() Removes & returns a random item
colors.clear() Removes all items
Access (No Index!)
for c in colors: print(c) Loop through all items (no fixed order)
Check / Set Operations
"red" in colors Returns True if "red" exists
a | b or a.union(b) Union — all items from both sets
a & b or a.intersection(b) Intersection — only common items
a - b or a.difference(b) Difference — in a but not in b
💡 remove throws an error if item missing — use discard when you're not sure if it exists.

📖 Dictionary

{ key: val }
✓ Ordered (3.7+) ✓ Mutable ✗ No Dup Keys ✓ Key-Indexed
Create student = {"name": "Ali", "age": 20}
Add / Update
student["grade"] = "A" Adds new key "grade" with value "A"
student["age"] = 21 Updates existing key "age" to 21
student.update({"city":"Delhi"}) Add/update multiple keys at once
Remove
student.pop("age") Removes key "age" & returns its value
del student["grade"] Deletes key "grade"
student.popitem() Removes & returns the last key-value pair
student.clear() Removes all key-value pairs
Access
student["name"] Gets value for key "name" → error if missing
student.get("name") Gets value — returns None if key missing
student.get("gpa", 0) Returns 0 if "gpa" key doesn't exist
student.keys() All keys → dict_keys(["name","age"])
student.values() All values → dict_values(["Ali", 20])
student.items() All key-value pairs as tuples
Check
"name" in student Returns True if key "name" exists
"name" not in student Returns True if key does NOT exist
💡 Always use .get() instead of [ ] when you're not sure if a key exists — it avoids KeyError crashes.
